🎬 Multimedia & Animation — syllabus checklist

Unit 1 — Introduction to Multimedia
Introduction to multimedia, usage of multimedia
Multimedia combines text, image, audio, video & animation into one interactive experience, used in education, entertainment, marketing & communication.
Multimedia hardware — connections, memory & storage, I/O & communication devices
Includes connections (cables/ports), memory/storage (RAM, drives), input/output devices (mic, speakers, display) and communication devices (network cards).
Multimedia software — text editing, OCR, painting & drawing tools
Text editors & word processors create content; OCR converts scanned text to editable text; painting/drawing tools create raster/vector graphics.
3D modeling & animation tools, image editing tools
3D modeling tools (like Blender) build 3D objects/animations; image editing tools (like Photoshop/GIMP) edit and enhance raster images.
Multimedia text — fonts & faces, hypermedia & hypertext
Covers fonts & typefaces, editing & design tools, and hypertext/hypermedia — linked, non-linear text navigation.
Multimedia image — source of images, light & colors, file formats
Covers image sources, the role of light & color, and common file formats (JPEG, PNG, GIF, etc.).
Multimedia sound — digital audio, MIDI, audio file formats
Covers digital audio recording, MIDI (an instrument protocol vs recorded digital audio) and common audio file formats (MP3, WAV).
Multimedia video — analog/digital video, file formats, shooting & editing
Covers analog vs digital video, common video file formats, and the basics of video shooting & editing.
Unit 2 — Synfig Studio & Animation Techniques
Intro to Synfig Studio 2D animation software
Synfig Studio is a free, open-source 2D vector animation software using keyframes and layers for smooth, scalable animation.
Animation basics — timeline, workspace, keyframe panel, rendering
The timeline sequences animation over time; the workspace holds the canvas & tool panels; the keyframe panel manages key animation points.
Interface — toolbox, canvas, panels, linking
The toolbox holds drawing/editing tools; the canvas is the drawing area; panels (layers, params) manage object properties; linking connects parameters dynamically.
Artwork construction — spline tool, outline layer, draw & brush tool
Spline tool draws smooth vector curves; outline layer defines shape borders; draw & brush tool create freehand strokes.
Gradient tool, text tool, width tool, blend method, masking
Gradient tool applies color transitions; text tool adds typography; width tool varies line thickness; blend method controls layer compositing; masking hides/reveals parts of a layer.
Adding & combining layers
Layers stack visual elements independently, letting animators combine and edit shapes, colors & effects without affecting other layers.
Slideshows, audio synchronization
Synfig supports sequencing static images into slideshows and aligning animation timing with audio tracks.
Keyframes — adding, duplicating, removing, reusing, onionskin, time loop layer
Keyframes mark key animation states; onionskin shows adjacent frames as a guide; a time loop layer repeats a segment of animation automatically.
Animation techniques — morphing, cut-out animation
Morphing smoothly transforms one shape into another; cut-out animation moves pre-drawn parts (like paper puppets) to create motion.
